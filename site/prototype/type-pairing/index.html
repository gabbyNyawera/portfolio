Recommendation

Two faces carry the page.
A third one signs it.

Blank Space Serif gives you the high-contrast, fashion-editorial headline. The script is not a second display face — it is a signature, used sparingly where a human hand belongs. Inter keeps doing the quiet work: body copy, navigation, labels.

The originals are commercial: Blank Space Serif is by TanType, and Rue de Miette and Sage Hill are licensed scripts. This page is set in the closest open-licence stand-ins so the pairing can be judged live. If you own the licences, the real files drop into the same three slots.

The voice. Headlines, project titles, pull quotes, and the italic G in the mark. High contrast only works large — it never sets body copy. Its italic becomes the one emphasis allowed inside a heading.

The one real decision

Which hand signs the page?

All three are open licence and set the same name at the same size. Only one can live in the system.

Sacramento

Gabrielle

Monoline, retro-signage. Closest to Sage Hill’s single-stroke elegance, with a little more warmth. Reads at 2rem and up. The safest everyday signature.

Dancing Script

Gabrielle

Bouncy, informal. The Rue de Miette energy — friendly, a bit kitchen-table. Lovely on a bistro brand; risks feeling casual for a product designer.

Pinyon Script

Gabrielle

Copperplate, engraved. Sage Hill’s formal cousin. Beautiful as a signature, but it reads wedding invitation unless the rest of the page is equally formal.

The other decision

How sharp should the serif be?

Three didones, same word, same size. Blank Space Serif sits between the first two: wide and high-contrast, with hairline serifs that stay crisp at display sizes.

Bodoni Moda

Quietly distinctive

Variable, with italic. The most complete stand-in: optical sizes, a real italic for quotes, and a G that holds the monogram. Recommended.

Italiana

Quietly distinctive

Wide, thin, one weight. The closest to Blank Space Serif’s airy caps. No italic and a single weight, so quotes and emphasis have nowhere to go.

Prata

Quietly distinctive

Warmer, sturdier. Lower contrast, more ink. Sits closer to editorial prose than to fashion, and holds up at smaller titles.

If we adopt it

Four rules keep it from turning costume

RuleWhy
Two script moments, never three The hero signature and the footer sign-off. A third — or a scripted byline under a quote — turns the page into a greeting card.
Script never sets content No headings, labels, navigation, dates or body. If it must be read, it is Inter or Bodoni.
Display ≥ 2rem, script ≥ 2rem Hairlines and connected strokes both fall apart below that. Body copy stays Inter at 1rem.
The mark follows the display face The G plate uses the new italic G. One face, one mark — no fourth font hiding in the logo.

Weight

Bodoni Moda normal + italic (97kb), Sacramento (23kb). Inter is already loaded, so the third face costs nothing extra.

Fallbacks

Display → Georgia, serif. Script → cursive, with the signature hidden if the face fails rather than shown in a fallback.

Licensing

The stand-ins are all SIL Open Font Licence. Blank Space Serif, Rue de Miette and Sage Hill need a web licence before they ship.
