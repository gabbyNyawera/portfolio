01 — PremiseOne material

One material, used twice a day.

Every page is built from the same paper, ink and signal. Dark sections are the same material at dusk, not a different theme.

Type does the expressive work

Scale, contrast and generous space create drama. Ornament is reserved for a few recurring marks: the arch, the grain, the long rule.

Nothing floats

Every element sits on a surface, in a grid, or on a deliberate line. Empty space is composed, not leftover.

One signal moment per screen

One band, one filled card, or the badge. Two and the colour stops being a signal and starts being a palette.

Before
Four type families. Three themes fighting each other. Bespoke spacing on every section. Placeholders that looked unfinished.
Now
Boska for display, Instrument Sans for structure, Inter for reading. One wash under every page. Five spacing tokens.

04 — LawsCopy these into the review

Five laws that save you a review.

Each one is a mistake the system has already made. Learn it here instead of in Figma.

01

Yellow never sets text on paper.

Breaks when
You put a yellow heading on white. It is 1.6:1 — it disappears.
Instead
Yellow carries black type at 12.1:1. It is always a ground, never a voice.
02

One signal moment per screen.

Breaks when
A yellow band sits under a yellow card and a yellow badge.
Instead
Keep one. Demote the others to a rule, a tag, or plain ink.
03

Cards are white on white.

Breaks when
A grey card sits on a white page to look “layered”.
Instead
Separation is a 1px hairline and letterpress shading — not a second fill.
04

Ink is #101010, never #000.

Breaks when
Pure black flattens the grain and kills the warm wash.
Instead
Use the ink token. It is the same value in type, chrome and dusk.
05

No label above a heading.

Breaks when
“01 — Philosophy” sits above “How I think”. That is the same idea twice.
Instead
Delete it. A section is a heading and, at most, one line of lede.

07 — Layout & motionParameters, not opinions

Five spacing tokens. One easing curve.

If a value is not in this table, it should not appear in a component. That is the whole enforcement policy.

TokenValueRole
--page-max76remPage width, centred
--reading-max42remReadable text width
--gutterclamp(1.25rem, 4vw, 4rem)Page edges, mobile-first
--section-yclamp(4.5rem, 9vw, 8rem)Section rhythm
--header-height76pxFixed chrome offset

--ease-out-expocubic-bezier(.16, 1, .3, 1)Every transition
180msHover and focus
600msReveals, 80ms stagger
800msLarge image scale

Reduced motion collapses transforms and durations to near zero and switches off the pointer light, magnetism, tilt and cursor. Content always reads without JavaScript — the wash, the type and the colour are all CSS.

If a value isn’t in the file, it doesn’t ship.
